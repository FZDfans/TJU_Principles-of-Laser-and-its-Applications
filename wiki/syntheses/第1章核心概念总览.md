# 第1章核心概念总览

## 主线

第 1 章的核心逻辑是：

```text
热平衡分布 → 光与物质三种作用 → 受激辐射相干放大 → 谱线增宽 → 激光形成条件
```

## 必掌握概念

1. [[wiki/concepts/玻尔兹曼分布.md]]：说明热平衡下高能级粒子少，不能自然形成反转。
2. [[wiki/concepts/自发辐射.md]]：普通光源主要机制，随机、非相干。
3. [[wiki/concepts/受激辐射.md]]：激光的基本过程，同频率、同相位、同偏振、同方向。
4. [[wiki/concepts/受激吸收.md]]：与受激辐射竞争，决定光是衰减还是放大。
5. [[wiki/concepts/爱因斯坦系数关系.md]]：三种跃迁几率和普通光源/激光差异。
6. [[wiki/concepts/光谱线增宽.md]]：自然、碰撞、多普勒；均匀与非均匀。
7. [[wiki/concepts/粒子数反转.md]]：受激放大的必要条件。
8. [[wiki/concepts/激光形成条件.md]]：增益介质、泵浦源、光学谐振腔。
9. [[wiki/concepts/光学谐振腔.md]]：多次放大、方向控制、频率选择。

## 高频考点

| 考点 | 应答核心 |
|---|---|
| 三种辐射过程比较 | 自发辐射、受激辐射、受激吸收的方向、公式和相干性 |
| 爱因斯坦系数 | $A_{21}/B_{21}$、$g_1B_{12}=g_2B_{21}$、$B_{12}=B_{21}$ 条件 |
| 普通光源 vs 激光 | 普通光源以自发辐射为主；激光通过反转和谐振腔让受激辐射占主导 |
| 粒子数反转 | 严格条件 $n_2/g_2>n_1/g_1$，非热平衡，需要泵浦 |
| 激光形成条件 | 增益介质 + 泵浦源 + 光学谐振腔，且增益补偿损耗 |
| 谱线增宽 | 自然/碰撞为洛伦兹型倾向，多普勒为高斯型；均匀/非均匀区别 |
