# TJU Principles of Laser and Its Applications Notes

这是一个面向《激光原理及应用》课程复习与长期维护的 Obsidian 知识库。仓库内容以 Markdown 笔记为主，配合原始课程资料、概念页、章节综述和考试复习材料，构成一个可检索、可交叉引用的激光原理学习 vault。

## 内容概览

本仓库目前主要覆盖：

- 第 1 章：辐射理论概要与激光产生条件
- 第 2 章：激光器的工作原理
- 第 3 章：激光器的输出特性
- 第 5 章：典型激光器介绍
- 第 6 章：激光精密测量
- 第 9 章：激光信息技术应用
- 第 10 章：激光科学前沿应用

核心组织方式参考 Karpathy-style knowledge base：保留原始资料，同时将知识逐步整理为可维护的 wiki 页面。

## 目录结构

```text

├── AGENTS.md              # vault 维护协议与知识库写作规范

│   ├── maps/              # 课程地图和知识图谱入口
│   ├── questions/         # 待研究问题、易错点、待核实 claim
│   └── tooling/           # 维护工作流与输出格式偏好
├── raw/                   # 原始资料层：教材、讲义、题解等 source-of-truth

├── templates/             # Obsidian 页面模板

```

## 推荐使用方式

1. 使用 Obsidian 打开本仓库根目录。
2. 从 `wiki/index.md` 或 `wiki/maps/激光原理课程地图.md` 开始浏览。
3. 复习章节时优先阅读 `wiki/syntheses/` 下的章节总览。
4. 查概念时进入 `wiki/concepts/`。
5. 需要核实公式、页码或原始上下文时，回到 `raw/` 中的教材或讲义。

## 笔记维护原则

- `raw/` 是原始资料层，原则上只读。
- `wiki/` 是工作知识层，可以持续改写，但应保留来源追踪。
- 重要结论尽量标注来源：文件名、章节、页码或题号。
- 公式在 Obsidian 中统一使用 `$...$` 和 `$$...$$`。
- 回答课程问题时，优先给出物理图像，再给公式、假设和易错点。

详见 `AGENTS.md`。
